# Large World Foundation

Status: **v3.0.0 internal milestone / planned public major scope**

`LargeWorld.hpp` adds the first large-world region and partition descriptors.

The API covers:

- region descriptors;
- settlement-to-region assignment;
- route-to-region assignment;
- caravan-to-region assignment;
- regional feature config;
- regional dependency config;
- cross-region references;
- regional snapshot summaries;
- regional event stream summaries;
- catalog validation;
- large-world summary and digest output.

This is a headless SDK foundation. It does not implement real cluster networking, shard servers, database engines or game clients.
