# Release Notes 3.0.0

City Life Core 3.0.0 adds the first large-world foundation and completes the v2.x multiplayer/server-authoritative preparation line from the detailed AI roadmap.

Highlights:

- v2.1.0 Action Authority for actor-scoped validation before server dispatch.
- v2.2.0 snapshot summaries for full/public/faction/settlement visibility scopes.
- v2.3.0 multiplayer command-log validation and authority-gated replay.
- v2.4.0 no-mutation economy safety reviews.
- v2.5.0 multiplayer load diagnostics.
- v2.6.0 pre-3 readiness reporting.
- v3.0.0 region descriptors and settlement/route/caravan region assignment helpers.

The release remains headless and transport-agnostic. It does not add networking, accounts, auth, matchmaking, database storage, real shard servers, UI or a game client.
