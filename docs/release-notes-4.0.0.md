# Release Notes 4.0.0

4.0.0 adds the multi-game platform foundation on top of the completed headless simulation SDK core.

Highlights:

- static platform module registry;
- genre profile metadata;
- content pack manifest validation;
- editor/admin query report;
- unified diagnostics report;
- platform-core example and tests.

The core remains headless and does not add UI, renderer, accounts, marketplace, billing, networking or cloud-specific infrastructure.
